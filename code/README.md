# 雾林回环 · 代码

> 完整可运行原型。依赖只有一个 `three`，零外部素材。

## 运行

**最简单**：双击 `E:\AiStudy\silentHill\start-mistloop.bat`

脚本会自动探测 node/npm 路径 → 首次运行装依赖 → 开独立窗口起服务器 → 等服务就绪 → 用 Chrome 打开游戏。
关闭那个名为 `Mistloop server` 的窗口即可停止。

**手动**：

```bash
cd E:\AiStudy\silentHill\code
npm install     # 只需一次
npm run dev
```

打开终端输出的地址（默认 `http://127.0.0.1:5199/`）。

- 需要 WebGL2（Chrome / Edge / Firefox 都可以）
- 点击「进入林子」开始（音频必须由用户手势启动）
- **建议戴耳机**

## 调试

URL 加 `?debug`：

- 启动时跑**环面无缝性自检**（对比 `(0.5,60)` 与 `(196.5,60)` 的树布局，必须一致）
- 每次显形在控制台打印 `[t=…s] manifest rule=… dist=… index=… gapScore=…`
- 每 2 秒打印一次帧率 / draw calls / 张力 / 恐惧值
- 控制台里 `window.mist` 暴露全部模块，`window.mist.director.log` 是完整显形日志

### 排查"走着走着忽然顿一下"

URL 再加 `?ft`（`?debug&ft`），一次长帧就在控制台打一行现场快照：

```
[顿挫] 559ms  @1.8s  走42m 阶段0 张力0.31 态=MANIFEST 音效应变0.67 音频节点5 q0
```

**为什么不能只看帧率**：帧率是 0.9 滑动平均。60 帧里 59 帧 4 ms、1 帧 400 ms，
平均只有 10.6 ms —— 记分板上一切正常，而玩家被闪了一下。
所以这里用的是 rAF 的**原始帧间隔**，抓的是孤立长帧（>34 ms）本身。

读数怎么用：

| 字段 | 说明了什么 |
|---|---|
| `走42m 阶段0` | 顿挫发生在什么进度上（区分"刚起步"和"走了很久"） |
| `态=MANIFEST` | 是不是正好在身影显形/消失的瞬间 |
| `音效应变` | 呼吸+心跳+风+雨+环境 的响度之和 |
| `音频节点5` | 未回收的一次性音效源个数 |

两个最容易搞混的判断，靠这两列分开：

- **顿挫时「音效应变」很高** → 嫌疑是音频（一次爆发的音效太多）
- **顿挫时「音效应变」正常、但发生时态有变化** → 音频不是元凶，去看几何 / LOD 换批

`音效应变` 与 `音频节点` 都是 `-1` 时说明音频还没初始化（没点"进入林子"）。

### 另外两种"闪烁"（症状很像，成因完全不同）

代码里能造成**瞬时视觉突变**的只有两处，都是有意为之的设计元素：

| 现象 | 来源 | 触发条件 |
|---|---|---|
| 画面反色/撕裂 0.3 s | `glitchCut` 关键帧（8% 处 `invert(1)`） | 身影消失时（`director._vanish`）；被直视 0.55 / 没被看到 0.2；终局 1.0 |
| 全屏淡入淡出 | `#fade` 叠加层 | 终局 `_enterClimax` 淡入 0.4 s，`_endClimax` 淡出 1.4 s |

`hud.flash()`（纯白/黑闪屏）目前**没有任何调用点** —— 它是预留接口，不会自发触发。
如果你看到的是"整屏白一下"，那只能是 `glitch` 的 `invert(1)` 那一帧。

区分方法：看**伴随的声音**。

- 听到一声金属感的下扫（`sting`）→ 是身影被直视后消失，属于正常设计
- 什么都没听到，而且画面像"卡住了"→ 是孤立长帧，用上面的 `?ft` 抓

## 目录

见 `../docs/CLAUDE.md` 的「目录即架构」一节。要点：

- `src/config.js` — **唯一的数值表**。改手感、雾、恐惧节奏、声音映射都只改这里
- `src/game/director.js` — 所有"什么时候发生什么"的决策都在这一个类里
- `src/entities/stalker.js` — 只负责"出现/移动/摆动"，不做任何决策
- `src/core/noise.js` — 周期噪声，是"环面无缝"的地基
