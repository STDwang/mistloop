# 雾林回环 · MISTLOOP

> 一个寂静岭式的第一人称恐怖短片游戏：**深山老林、浓雾、阴沉天。你一直走，却始终走不出去。**
> 在移动与转身的过程中，雾气深处会浮现诡异身影；每一次出现都比上一次更近，
> 它越近，你越听得见自己的呼吸，越听不见这座森林。

本仓库是「**想法 → 一套可执行的提示词上下文 → 可运行原型**」的完整交付物。

## 运行

```bash
cd E:\AiStudy\silentHill\code
npm install
npm run dev
```

浏览器打开终端输出的地址（默认 `http://127.0.0.1:5199/`）。

**要求**：支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox 均可）。无需 WebGPU。
**注意**：点击画面开始（音频必须由用户手势启动）。

**操作**

| 键 | 作用 |
|---|---|
| `W A S D` | 移动 |
| `Shift` | 奔跑（消耗体力） |

| `F` | 手电筒开关 |
| `Esc` | 暂停 / 释放鼠标 |
| `F1` | 帮助 |

## 这个游戏在做什么（一句话版）

> 你在一个**数学上的环面**里行走——地形、树、地标全部由**以 196 米为周期**的程序化噪声生成。
> 你走了三公里，坐标却回到了原点，而你自己不会察觉，因为雾只让你看见 40 米。
> 与此同时，一个**只在你视线之外移动**的身影，正按一张固定表一次次逼近。

三个机制：

1. **空间回环**：环面世界 + 指数雾 + 固定周期地标 → 无法逃离，且"似曾相识"是真的。
2. **身影规则**：只在**移动/转身/久站**时显形；**盯着看它消失，移开视线它会靠近**。
3. **声音张力**：身影越近 → 环境声被"闷住"并压低，呼吸声放大，心跳加快，次声嗡鸣增强。

细节见 `docs/DESIGN.md`。
