## 1. 同类作品（玩法/氛围参照）

| 作品 | 借鉴点 | 不借鉴点 |

### 一句话提炼
> 本作 = **P.T. 的循环结构** + **Slender 的距离阶梯** + **SCP-173 的视线规则** + **Anatomy 的静默**。

## 2. 技术资料

| 主题 | 资料 | 用在哪 |
|---|---|---|
| 周期性（可平铺）噪声 | **Perlin, "Improving Noise" (2002)**；`libnoise` 的 tileable 实现 | `core/noise.js` 的周期 fBm |
| 环面世界与无缝回绕 | **"Toroidal worlds" / seamless world wrapping** 的通用做法；《Proteus》《No Man's Sky》的流式方案对比 | `director.js` 的回绕 |
| 指数雾的物理来源 | **Beer–Lambert 定律** `I = I₀·e^(−σd)` | `FogExp2` 密度取值 |
| 索引基值的视觉解释 | 索引基值（Index of Refraction 之外的）——**雾中对比度衰减**（aerial perspective）| 雾密度 → 能见度换算 |
| 视线夹角与显形 | **"peripheral vision" 的视野角研究**（人眼有效识别约 ±30°） | R6 方位规则 0.25~0.85 rad |
| Web Audio 调度精度 | **"A Tale of Two Clocks"（Chris Wilson）** | `setTargetAtTime` 与音频调度 |

### 雾密度 ↔ 能见度换算表（本项目的取值依据）

`FogExp2` 的遮蔽因子 = `1 − e^(−(density·d)²)`。取"遮蔽 50%"作为能见度定义：

| 密度 | 50% 遮蔽距离 | 80% 遮蔽距离 | 观感 |
|---|---|---|---|
| 0.012 | 69 m | 96 m | 薄雾 |
| **0.018** | **46 m** | **64 m** | 本作起始 |
| 0.023 | 36 m | 50 m | 压迫 |
| **0.028** | **30 m** | **41 m** | 本作后期 |
| **0.038** | **22 m** | **30 m** | CLIMAX 前 |

> 设计约束：**能见度必须 ≤ 周期长度 / 4**。196/4 = 49 m。
> 所以密度下限是 0.017。这一条决定了"周期定为 196 米"这个选择。

## 3. 声音参考（听感目标）

| 目标听感 | 参照 | 合成手段 |
|---|---|---|
| 没有鸟、没有虫的森林 | 真实录音里"死寂"的林子 | 只有低频风 + 极远的中频噪声 |
| 呼吸 | 自己跑步后的呼吸 | 噪声 + 非对称波形整形（吸气短、呼气长） |
| 心跳"进画面" | 恐怖片里心跳从背景变成主观声 | 52 Hz 正弦 + 双峰整形 LFO，随张力升调加速 |
| 低频不安 | 次声（<20 Hz 的生理反应）的**可听化代理** | 41.2 / 41.9 Hz 双正弦拍频（≈0.7 Hz 拍） |
| 远处树枝断裂 | 冬夜林子里的"咔" | 噪声爆 → 带通 300 Hz Q4，1.5 s 衰减 |
| 耳语 | 听不清的多人低语 | 噪声 → 高 Q 带通（~1800 Hz）随 0.21 Hz 扫频 |

## 4. 反参考（刻意避开的东西）

| 避开 | 为什么 |
|---|---|
| 血液、断肢、怪物特写 | 本作是**心理**恐怖，不是 body horror |
| 日记 / 录音带 / 便条 | 一旦给解释，恐惧就变成"解谜" |
| 战斗 / 武器 | 有武器就会期待"能赢" |
| 成就 / 收集物 | 让玩家把注意力从"环境"移到"任务列表" |
| 跳脸音效（jump scare） | 只在 CLIMAX 用一次，全程仅此一次 |
| 结尾动画 | **它不结束。**这是设计，不是偷懒 |
