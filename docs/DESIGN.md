# 设计圣经 · 雾林回环

> 这份文档回答一个问题：**"你描述的这种感觉"到底该怎么变成可实现的机制。**
> 你原话里的三件事——① 走不出去、② 转身看见身影、③ 越近声音越不对——
> 在这里被拆成三组可调参数。

---

## 0. 一句话体验

> **你被一片 196 米见方的森林困住了，而这片森林在你脚下无限重复。**
> 你走了三公里，回来时看见同一棵断树。
> 有什么东西一直跟着你，但它只在你不看的时候移动。

---

## 1. 支柱一：走不出去（空间回环）

### 1.1 为什么不能用"无限地形"

常见做法是分块流式加载无限地形。它解决了"世界有限"，但**没有解决"打圈"**——
玩家仍在真实坐标系里直线前进，方向感是可靠的，恐惧就没有立足点。

你要的是**「似乎一直在一个地方打圈」**。所以我们要的不是无限，是**环面（torus）**。

### 1.2 环面的数学

把世界定义为一个 **196 m × 196 m 的环面**：坐标对周期取模。

```
world(x, z)  ≡  world(x mod T, z mod T)        T = 196
```

只要**所有世界内容都是 x、z 的周期函数**，环面就是**天然无缝**的——不是"想办法遮掩接缝"，
而是**根本不存在接缝**。

实现靠三件事：

| 元素 | 周期化的做法 |
|---|---|
| 地形高度 | 周期性值噪声 fBm：八度 o 的格点频率取 `L·2^o`（L 为整数），格点索引对频率取模 → 天然以 T 为周期 |
| 树 / 草 | 格点哈希：格点索引 `(i, j)` 先 `mod K`（`K·cell = T`）再哈希 → 走到第 K 格就是第 0 格 |
| 地标 | 单个地标按 2D 晶格复制；每帧只把**离玩家最近的那一份**摆到正确位置 |

**无缝性证明（关键一步）**：玩家穿越边界时，我们把他的坐标减去 T。
摄像机的世界位移是 `-T`；而地形网格的对齐点 `round(p/T)·T` 恰好也变化 `-T`。
两者**位移完全相等**，所以**相对画面一动不动**。
树、草、地标由"相对玩家的格点"生成，格点索引变化正好是 `±K`，取模后完全相同。
→ **玩家永远不可能看到接缝，因为接缝不存在。**

### 1.3 为什么玩家不会察觉

- **雾**：能见度约 40 m，而周期是 196 m。玩家看不到"重复"这件事的全貌。
- **格点抖动**：每棵树在自己 4 m 的格子内有随机位移、旋转、缩放，密度也不是 1.0 而是 0.72 → 视觉上不像网格。
- **地标锚点**：一个**残破石龛**固定在某组环面坐标上，玩家每走一圈都会遇到它一次。
  这不是 bug，**这就是"似曾相识"的来源**——它是被设计出来的既视感。

### 1.4 「走不出去」的叙事反馈

HUD 上只有一个不断增长的距离数字。它是真的，因为你确实在走。
每完成一次回绕（一圈），字幕说一句话，逐圈加重：

| 圈 | 字幕 |
|---|---|
| 1 | 你确定刚才那棵树……？ |
| 2 | 你已经走过这里了。 |
| 3 | 你的指南针在转。 |
| 4 | 「路」这个词现在没有意义了。 |
| 5+ | 你听见自己说：再往前一点就到了。 |

> **设计意图**：玩家迟早会意识到"我在打圈"。这个意识本身不是败笔，**是这个游戏的高潮前置**。
> 真正要守住的是——他意识到之后**仍然走不出去**。

## 2. 支柱二：那个身影

### 2.1 唯一的行为模型

```
                    ┌──────────── 移动 / 转身 / 久站 触发 ────────────┐
                    ▼                                              │
  DORMANT ──触发──► MANIFEST ──被注视 1.1s──► VANISH ──冷却──► DORMANT
                       │                                          ▲
                       ├── 未被注视：以 (1.1 + 3.2·恐惧值) m/s 逼近 ─┤
                       │                                          │
                       └── 距离 < 4m ──► CLIMAX ──黑屏──► 阶段+1 ──┘
```

**核心规则（一句话）**：

> **你看着它，它消失。你不看它，它靠近。**

这条规则的代价结构是精心设计的：

- 注视 = 立刻摆脱（但代价是**一次 sting 音效 + 恐惧值 +0.12 + 下一次显形更近**）
- 不注视 = 它继续靠近（代价是**你放弃了唯一的应对手段**）

于是玩家自己制造了压力：**他必须选择不看那个东西。** 而人对"不看"这件事的控制力很差。

### 2.2 触发规则（你要求的「移动转向过程中 / 或其他规则」）

| # | 规则 | 判定 | 设计意图 |
|---|---|---|---|
| R1 | **转身中显形** | 1.2 s 窗口内累计 `|Δ偏航| > 2.2 rad`，且掷骰通过 | 玩家最放松的时刻是"随便看看" |
| R2 | **行进中显形** | 上次显形后连续前进 > `lerp(46, 17, 恐惧值)` m | 走路时人进入自动驾驶，最不设防 |
| R3 | **久站显形（背后）** | 静止 > 7 s，显形在**身后** ±24° | "我在听"的代价 |
| R4 | **回绕显形** | 每次穿越环面边界必触发 | 把"轮回"和"它"绑定成同一件事 |
| R5 | **环境骰子** | 每秒 `2% × (0.4 + 恐惧值)` | 保证低恐惧期也有偶发压迫 |
| R6 | **显形必须在你视野边缘** | 方位 = 偏航 + `±(0.25~0.85) rad` | 逼你**转头**去确认，而不是直接摆在正前方 |

> R6 是整套设计里最"电影"的一条：**它逼玩家自己完成那个回头动作。**
> 恐惧是玩家自己转头看出来的，不是游戏喂给他的。

### 2.3 显形距离阶梯

```
78  64  52  42  34  27  21  16  12  9  6.5  4.5   （米）
└── 第一次：雾里一个说不清的竖条 ──┘        └─ 最后一次：你几乎能碰到 ─┘
```

- 每次"被注视消失"或"自然消失"，索引 +1 → 下一次更近
- **CLIMAX 后不清零，而是回退到 `min(4 + 阶段, 8)`** —— 重开一段，但起点已经比上一段近
- 3.5 m 是硬底线：越过即 CLIMAX（无法回避，这是必然结局）

### 2.4 为什么"盯着看会消失"不烂

因为它**不是逃脱**，是**延期**。每一次注视都是一个可听见的代价（sting），
而阶梯只会前进不会后退。玩家的最佳策略让游戏更快结束——这是恐怖游戏里少数成立的悖论。

## 3. 支柱三：声音（你点名要的部分）

> 你原话：**「越逼近越能感受到周围声音的变化（比如呼吸声变大，环境声音变小等）」**
> —— 这就是本作的主音量旋钮。我们把它做成**一个数**：`tension`。

### 3.1 tension 的来源

```
proximity = clamp01(1 - 身影距离 / 80)
tension   = max(恐惧值, proximity)      // 0 = 平常，1 = 它就在你背后
```

`恐惧值` 本身随时间、轮次、每次显形缓慢上升，且**从不完全回落**——所以越到后期，环境本身越糟。

### 3.2 张力 → 参数映射（完整表，实现于 `src/audio/audio.js`）

| 通道 | 合成方式 | tension 0 | tension 1 | 强度 |
|---|---|---|---|---|
| **环境底噪** | 白噪 → 低通 | 增益 1.00，截止 18 kHz | 增益 **0.08**，截止 **380 Hz** | ★★★ 这就是"环境声变小" |
| **风** | 带通噪声 + 0.07 Hz LFO | 0.22 | 0.05 | ★ |
| **呼吸** | 带通噪声 + 波形整形 LFO | 0（听不见） | 0.90，速率 **0.22→1.05 Hz** | ★★★ 12→63 次/分 |
| **心跳** | 52 Hz 正弦 + 双峰整形 LFO | 0 | 0.55，**52→140 BPM** | ★★ |
| **次声嗡鸣** | 41.2 / 41.9 Hz 双正弦拍频 | 0.10 | 0.80 | ★★ 身体先于耳朵感知 |
| **耳语** | 噪声 → 高 Q 带通 + 0.21 Hz 扫频 | 0 | 0.35（中后期才出现） | ★★ |
| **主低通** | 串联在所有通道前 | 18 kHz | **380 Hz** | ★★★ 全局"闷住" |

> **实现细节**：所有增益变化用 `setTargetAtTime(t, now, 0.35)`。
> 直接赋值 `.value` 会产生咔哒声，这是新手最常犯的错。

### 3.3 一次性音效（事件驱动，非循环）

| 事件 | 合成 | 用途 |
|---|---|---|
| `sting` | 3 个失谐锯齿 220→40 Hz 下扫 + 共振低通 + 噪声爆 | 显形消失 / 逼视失败 |
| `climax` | sting(1.0) + 反向膨胀 + 全频噪声墙 | 唯一一次贴脸 |
| `crack` | 噪声爆 → 带通 300 Hz Q4，1.5 s 衰减 | 远处树枝断裂，不定期 |
| `snap` | 噪声爆 → 带通 1.8 kHz，0.12 s | 脚下枯枝，与脚步随机绑定 |
| `footstep` | 噪声爆 → 带通 1.1 kHz + 70 Hz 体感低频 | 每步 |
| `bell` | 正弦 440/660 + 长衰减 | 靠近神龛 30 m 内偶发 |

### 3.4 音频的"预兆纪律"

**显形前 0.4 秒，必须先有一次 `crack` 或呼吸速率突变。**
不许出现"先看见再听见"。违反这条的改动一律回退。

## 4. 视觉语言

| 项 | 值 | 理由 |
|---|---|---|
| 雾类型 | `FogExp2` | 指数雾才是"浓"，线性雾看着像贴图 |
| 雾密度 | `0.018 → 0.038`（随天气/阶段上升） | 能见度 40 m → 18 m。**雾是唯一的关卡设计师** |
| 雾色 | `#8E9A92` 灰绿 | 纯灰会觉得"没颜色"，加一点绿会觉得"脏" |
| 天空 | 上下渐变 `#39423F → #8E9A92` | 阴天，无太阳，光从"到处都是"来 |
| 环境光 | `HemisphereLight` 0.34，地面色略暖 | 阴天的漫射感 |
| 主光 | 无一盏"太阳"。只有**手电** | 光是玩家的工具，不是场景的装饰 |
| 手电 | `SpotLight` 26° / 半影 .55 / 距离 46 | 收得很窄 → 未知区域最大化 |
| 手电体积光 | 加性材质的锥体，随距离平方衰减 | 便宜 90%、效果 70% 的雾中光柱 |
| 地面 | 深泥 `#2B2A20` ↔ 苔 `#39402C` 顶点色混合 | 阴湿腐殖质 |
| 树 | 全部**枯死**：细高、无叶、枝桠下垂 | 有叶的树会让森林显得"有生机"，与主题冲突 |
| 后处理 | DOM 叠加：SVG 噪声颗粒 + 径向暗角 + CSS 滤镜降饱和 | 零依赖、零兼容风险 |
| 故障 | 显形消失瞬间给 canvas 加 260 ms 抖动/反相/色偏 class | 唯一允许的"廉价"效果，因为它是**心理性**的 |

## 5. 恐惧节拍曲线（0–10 分钟）

| 时间 | 阶段 | 雾 | 台阶 | 声音 | 玩家感受 |
|---|---|---|---|---|---|
| 0:00 | 引入 | 0.018 | — | 只有风与脚步 | 「就是片林子」 |
| 0:45 | 第一次 | 0.018 | #1 @ 78m | 远处一次 crack | 「那边是不是有东西」 |
| 1:40 | 确认 | 0.020 | #2 @ 64m | 呼吸首次可闻 | 「它在动」 |
| 2:30 | 学会 | 0.021 | #3 @ 52m | 发现"盯着看会消失" | 「我有办法」 |
| 3:30 | 失效 | 0.023 | #4 @ 42m | sting 变频繁，环境开始闷 | 「代价是什么」 |
| 4:30 | 轮回 | 0.025 | #5 @ 34m | 字幕：你已经走过这里了 | 「我在打圈」 |
| 5:40 | 逼近 | 0.028 | #6 @ 27m | 心跳进入画面 | 「它一直在跟着」 |
| 6:50 | 呼吸困难 | 0.031 | #7 @ 21m | 呼吸 0.7 Hz，环境 -10 dB | 「我不能看它」 |
| 8:00 | 崩溃 | 0.034 | #8 @ 16m | 耳语层进入 | 「我不该停下的」 |
| 9:00 | CLIMAX | 0.038 | 贴脸 | 全频墙 + 黑屏 | —— |
| 9:20+ | 新阶段 | 0.040 | 起点已更近 | 更暗、更闷、更快 | 「这次不会更好了」 |

> 这张表就是 `src/game/director.js` 里 `phase` 的实现依据。
> **想要更短的体验，把阶段时长乘 0.4；想要更折磨，乘 2。**——这是唯一需要调的东西。

## 6. 反套路设计说明（给未来的自己）

1. **不放 jump scare**。第一次贴脸只在 CLIMAX。中途所有"吓到"都来自玩家自己的余光与脑补。
2. **不给武器、不给冲刺逃离**。奔跑存在，但会消耗体力并**加快呼吸**——逃跑本身让你更响。
3. **不给解释**。没有笔记、没有 NPC、没有结局演出。唯一的信息是字幕里那几句近乎自言自语的话。
4. **不结束**。CLIMAX 之后不是通关，是**下一段更糟的循环**。这才是"走不出去"。
